# Erkennung und Identifizierung von Verkehrszeichen
Entwickeln Sie ein Deep-Learning-Modell, das Verkehrsschilder in Bildern oder einem Videostream erkennen und klassifizieren kann. Dieses Projekt stellt eine praktische Anwendung der Computer Vision dar und ist ein grundlegender Bestandteil von Systemen für autonomes Fahren.
Erkennung deutscher Straßenverkehrszeichen
50,000 Bilder mit > 40 Klassen
https://benchmark.ini.rub.de/gtsrb_dataset.html
 - GTSRB_Final_Training_Images.zip
 - GTSRB_Final_Test_Images.zip
 - GTSRB_Final_Test_GT.zip

## Projektstruktur

```
traffic-sign-recognition/
├── data/
│   ├── raw/                        # Originale ZIP-Dateien (nicht in Git)
│   ├── processed/
│   │   ├── train/                  # Trainingsbilder nach Klasse (00000–00042)
│   │   ├── test/                   # Testbilder (.ppm)
│   │   └── meta/
│   │       ├── Train.csv           # Pfad + Label + ROI für alle Trainingsbilder
│   │       └── Test.csv            # Pfad + Label + ROI für alle Testbilder
│   └── unzip_dataset.py            # Entpackt ZIPs und erstellt Train/Test.csv
│
├── notebooks/
│   ├── 00. Kick-Off.md
│   ├── 01. EDA.ipynb               # Explorative Datenanalyse
│   ├── 02. Model-Training.ipynb    # CNN-Modelltraining
│   ├── 03. Model-Evaluation.ipynb  # Auswertung & Confusion Matrix
│   └── 
│
├── src/
│   ├── data/
│   │   └── data_loader.py          # Bilder laden, vorverarbeiten (Resize, Graustufen)
│   ├── models/                     # Modellarchitekturen
│   └── app.py                      # Demo-Anwendung
│
├── models/                         # Gespeicherte Modelle (nicht in Git)
├── reports/figures/                # Diagramme & Auswertungsgrafiken
└── requirements.txt
```
